## 연습: 공개 데이터셋(TACO)으로 미리 돌려 보기
`practice/practice_taco.ipynb` — 사진을 찍기 전에 hw02 코드 흐름을 익히는 **연습용** 노트북 (제출·점수 확인 서버 사용 안 함).
TACO의 Drink can / Drink carton / Clear·Other plastic bottle 상자를 잘라 `can / carton / pet`으로 만들고, 빈칸 ①~④를 채운 버전으로 학습한다.

CPU에서 끝까지 실행해 본 결과 (훈련 356장, 검증 88장, 25에폭):
- 검증 정확도 약 0.70 (최고 0.75)
- 클래스별: can 0.73 (29/40), **carton 0.13 (1/8)**, pet 0.78 (31/40)
- 종이팩이 44장뿐이라 거의 못 맞힘 → **실제 과제에서는 클래스별 장수를 비슷하게, 종이팩도 충분히** 찍어야 한다.
- TACO는 길바닥에 버려진 쓰레기 사진이라 실제 테스트 사진(손에 든 것, 탁자 위 등)과 조건이 다르다. 내 사진으로 하면 정확도는 달라진다.

### 튜닝 실험 결과 (practice 노트북 8절, CPU, 30에폭, 검증 88장)

| 설정 | 전체 | 클래스 평균 | can | carton (8장) | pet |
|---|---|---|---|---|---|
| A 증강 없음 | 0.73 | **0.67** | 0.75 | 0.50 | 0.75 |
| B 약한 증강 | 0.70 | 0.58 | 0.78 | 0.25 | 0.72 |
| C 중간 증강 | 0.74 | 0.58 | 0.78 | 0.12 | 0.82 |
| D 강한 증강 | **0.75** | 0.62 | 0.65 | 0.25 | **0.95** |
| E 중간 증강 + 클래스 가중치 | 0.70 | 0.65 | 0.72 | 0.50 | 0.72 |
| F 중간 증강, lr 0.003 | 0.73 | 0.60 | 0.70 | 0.25 | 0.85 |

- 전체 정확도는 모두 0.70~0.75로 **차이가 검증 사진 2~4장 수준** → 뚜렷한 승자 없음.
- 클래스 평균의 차이는 거의 종이팩 8장 중 1~4장 차이에서 나옴(우연에 가까움).
- 결론: 설정보다 **데이터(특히 부족한 클래스의 장수)가 병목**. 내 사진은 클래스를 고르게 찍고, 검증 사진도 클래스당 15장 이상 되도록(=클래스당 75장 이상) 찍어야 비교가 의미 있어진다.
