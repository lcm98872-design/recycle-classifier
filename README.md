# hw02 재활용품 분류기 (개인 과제)

직접 찍은 캔 / 종이팩 / 페트병 사진으로 3클래스 분류기를 만든다.
ImageNet 사전학습 ResNet-18의 특성 추출부를 동결하고 `fc`를 출력 3개로 바꿔 학습한다.

- 과제 안내: https://ralbu85.github.io/lecture_deeplearning/assignments/hw02/hw02.html
- 원본 노트북: https://github.com/ralbu85/lecture_deeplearning_labs/blob/main/hw02.ipynb

## 연습: 공개 데이터셋(TACO)으로 미리 돌려 보기
`practice/practice_taco.ipynb` — 사진을 찍기 전에 hw02 코드 흐름을 익히는 **연습용** 노트북 (제출·점수 확인 서버 사용 안 함).
TACO의 Drink can / Drink carton / Clear·Other plastic bottle 상자를 잘라 `can / carton / pet`으로 만들고, 빈칸 ①~④를 채운 버전으로 학습한다.

CPU에서 끝까지 실행해 본 결과 (훈련 356장, 검증 88장, 25에폭):
- 검증 정확도 약 0.70 (최고 0.75)
- 클래스별: can 0.73 (29/40), **carton 0.13 (1/8)**, pet 0.78 (31/40)
- 종이팩이 44장뿐이라 거의 못 맞힘 → **실제 과제에서는 클래스별 장수를 비슷하게, 종이팩도 충분히** 찍어야 한다.
- TACO는 길바닥에 버려진 쓰레기 사진이라 실제 테스트 사진(손에 든 것, 탁자 위 등)과 조건이 다르다. 내 사진으로 하면 정확도는 달라진다.
